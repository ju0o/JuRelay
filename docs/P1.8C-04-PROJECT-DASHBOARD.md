After bootstrap, show a bounded selected-project dashboard:

`Project → Goal → Task → Agent → Runtime State → Next Action`

without reading raw JSON or consuming the full `relay_pm_get_dashboard` payload.

## API

`relay_pm_get_project` (existing tool, no longer a stub)

- Optional `projectId` overrides the view for this read only (never persists selection)
- Resolution: ARGUMENT → SELECTED → LAST_ACTIVE → SCOPE
- Pure read; zero mutations

Bounded fields: project/path, desired assignment, goal, current task
(runtimeState distinct from executionState), nextAction/nextActionText,
counts, warnings, ≤5 recentTasks.
